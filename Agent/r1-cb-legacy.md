## §4 失败教训与已知坑（最有价值部分）

1. **"整份下发会推倒已验证代码"**：GPT 3190 行清单假设从零，与已有 60+ commit 大面积重叠（4 已实现 / 19 部分 / 18 缺口）。教训：外部设计必须先做现状映射再派单（全史 L264-266）。
2. **测量系统自证为伪**：OrderTrace 把 CB 内部 `Record` 误标为"原生覆盖"，"原生占 35–80%"结论作废，旧三场数据全废；低样本（35 次 0 失败）不能包装成可靠性（全史 L485-487、L553-565）。**[核心警示：指标不可自证，须独立验证]**
3. **ATC-4 四个 P0 全是自身缺陷**：感知刷新失效 / 未知敌算已接敌 / 兵力算两遍 / 预备队误判——"准允投入"建立在假战场上（全史 L440-449）。
4. **D 组零 Acquire**：实验条件过窄（远出且 Denied 的步兵实战中不存在），非代码故障却结构性失败，只能转 Route A（全史 L543-551）。
5. **命令互刷催生冻结**：曾"靠调用顺序表达优先级"（protect 后再 brace，后写者胜）→ 直接催生 CPS 功能冻结令（全史 L509-511）。
6. **个体层空白却占 80% 观感**：X 系列自我诊断发现外部清单个体层任务=0，而玩家"聪明感"恰在个体层（全史 L278-280）——与宪章 §19-20 不进个体层形成张力，需明确移交边界。
7. **架枪过早触发**：头号"看起来蠢"来源，与推进意图打架（PRD §9.1，t71 修复）。
8. **范围蔓延史**：早期 F13–F25（统帅/观战/导播）全讲"AI 怎么想、玩家怎么看"，最终拆分出独立项目（全史 L58-66）。
9. **规范一致性债**：Route A 玩家豁免未读 MCM 开关，与另 7 模块不一致，属缺陷非偏好（CPS-4 报告 §3a）。
10. **文档债**：结论跨 4–6 份文档复写，裸"文件:行"引用随提交漂移（CPS-4 报告 §5）。

## §5 旧代号体系是否继承新 CB-00X

**建议：不继承 T/F/X 的功能编号语义，保留 CPS/ATC 治理代号。**

- **T0–T39**：不继承为新代码体系。它是外部提案映射表，"T"前缀含义且内部已与 F/t/X/ATC/CPS 多套并存导致 **B 系列至今未裁决撞名**。但其"差异分析/现状映射"工作法值得继承为流程纪律。
- **F0–F12**：部分可继承指向稳定功能模块，但需重新对齐宪章六环节；注意 F 与 S 曾撞名，须清理。
- **X0–X7**：多数（X2 手活 / X3 朝向 / X4 解阵）属个体层，**与新宪章 §19-20 非目标冲突，应废弃或移交**；X5 站位通用机制可沿用。
- **ATC / CPS**：**价值最高，必须保留为 2.0 基座**。CPS 控制面收口（唯一仲裁 + 三条硬门）是 Formation 层级指挥可成立的前提，其"影子判定 → 不谎称控制"的纪律直接回应宪章 §16 指挥延迟与可审计性。
- **结论**：新 `CB-00X` 取代 T/F/X 的功能编号职能；CPS/ATC 作为架构治理代号保留；彻底弃用 B/G/S 等易撞名体系。旧代号仅作历史溯源，不进新代码命名。
